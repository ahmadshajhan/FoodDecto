# 🍔 FoodDecto AI

## AI-Powered Food Detection and Calorie Estimation

FoodDecto AI is a computer vision project that uses YOLOv8 Object Detection and Convolutional Neural Networks (CNNs) to identify food items from images and estimate nutritional information.

---

## Features

* Real-time Food Detection
* Food Classification using CNN
* Calorie Estimation
* Nutritional Information
* Bounding Box Visualization
* Multiple Food Detection
* High Accuracy Recognition
* Healthy Food Recommendation

## Installation

Clone Repository

git clone https://github.com/ahmadshajhan/FoodDecto.git

cd FoodDecto

Create Virtual Environment

python -m venv venv

source venv/bin/activate

Install Dependencies

pip install -r requirements.txt

---

## Training

python train.py

---

## Detection

python detect.py
